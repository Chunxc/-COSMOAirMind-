# AirMind — 空压站智能协同调度智能体

AirMind 是一个面向工业空压站场景的智能调度应用，基于 COSMO Code 开发，探索多台空压机在不同需求、压力约束、设备状态和电价条件下的协同调度。

## 核心功能

- 智能驾驶舱：展示供需、压力、功率及设备状态
- 多机协同调度：比较最低能耗、最高稳定性和综合优化方案
- 负荷预测：展示短期用气需求趋势
- 设备健康评估：将设备健康状况纳入调度评价
- 事件仿真：模拟设备故障、需求变化和压力异常
- AI 调度助手：解释候选方案与调度原因
- 调度报告：汇总运行状态与方案评估结果

## 技术与验证说明

当前版本主要使用模拟数据开展功能演示和逻辑验证。自动化测试记录为 65 项通过、0 项失败。测试结果不代表真实工业现场验证或实际节能收益。
